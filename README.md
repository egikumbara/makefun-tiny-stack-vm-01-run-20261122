# Tiny Stack VM

A tiny stack virtual machine for the make.fun bounty `tiny-stack-vm-01-run-20261122`: 32-bit wrapping integers, a 256-value stack, branches, calls, 256 words of memory, byte input/output, and ten traps with their own exit codes.

Run: `node main.ts` (Node 22). It reads `/input/<id>/program.bin` + `input.bin` for every instance and writes `/output/<id>/stdout.bin` and `/output/<id>/exit.txt`. `MAKEFUN_INPUT_DIR` / `MAKEFUN_OUTPUT_DIR` override the paths.
